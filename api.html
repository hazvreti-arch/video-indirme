Vidora API

Programatik medya işlemleri için API v1.

Authentication

Hesabından bir API key oluştur ve X-API-Key header'ında gönder.

POST /api/v1/download
GET  /api/v1/status/:job_id
GET  /api/v1/analyze?url=...

Example

curl -X POST https://YOUR-DOMAIN/api/v1/download \\
  -H "X-API-Key: vk_live_..." \\
  -H "Content-Type: application/json" \\
  -d '{"url":"https://...","quality":"1080","container":"mp4"}'
